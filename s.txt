========================================================
        SERIALIZATION & DESERIALIZATION
========================================================

1. SERIALIZATION
-----------------
Python Object → File

Meaning:
Object ko file me save karna = Serialization

Example:
List → .pkl file


2. DESERIALIZATION
------------------
File → Python Object

Meaning:
Saved file se object ko wapas load karna
= Deserialization


========================================================
                 PICKLE
========================================================

Import:
import pickle

SAVE / SERIALIZE:
-----------------
with open("data.pkl", "wb") as file:
    pickle.dump(data, file)

LOAD / DESERIALIZE:
-------------------
with open("data.pkl", "rb") as file:
    data = pickle.load(file)


========================================================
                 JOBLIB
========================================================

Import:
import joblib

SAVE / SERIALIZE:
-----------------
joblib.dump(data, "data.pkl")

LOAD / DESERIALIZE:
-------------------
data = joblib.load("data.pkl")


========================================================
             FILE MODES
========================================================

"wb" = Write Binary
      → Save data

"rb" = Read Binary
      → Load data


========================================================
             LIST USING PICKLE
========================================================

import pickle

data = [10, 20, 30, 40]

# Save
with open("list.pkl", "wb") as file:
    pickle.dump(data, file)

# Load
with open("list.pkl", "rb") as file:
    data = pickle.load(file)

print(data)

========================================================
                 MAIN DIFFERENCE
========================================================

SERIALIZATION:
Object → File

DESERIALIZATION:
File → Object


PICKLE:
pickle.dump() → Save
pickle.load() → Load

JOBLIB:
joblib.dump() → Save
joblib.load() → Load


========================================================
             ⭐ 4 LINES TO REMEMBER
========================================================

pickle.dump()       → Save
pickle.load()       → Load

joblib.dump()       → Save
joblib.load()       → Load


========================================================
             ⭐ EXAM DEFINITIONS
========================================================

Serialization:
Converting a Python object into a file format
for storing it.

Deserialization:
Loading the stored object from a file back
into Python.
